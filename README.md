## Overview

The repository organizes my university materials by semester and course. It helps me track my progress and quickly find relevant files when reviewing topics or preparing for assessments.

## Repository Structure

Materials are grouped by semester and then by course. Each course contains a `README.md` and only the applicable standard directories: `materials/`, `work/`, and `project/`.

| Directory | Contents |
| --- | --- |
| `materials/` | Syllabi, lectures, books, manuals, and other provided learning materials |
| `work/` | Labs, practice assignments, homework, tests, and other student work |
| `project/` | A separate substantial coursework deliverable or semester project |

Subdirectories such as `work/labs/` or `materials/lectures/` are used only where they meaningfully organize the available files. Verified syllabus information is recorded in each course's English-language `README.md`.

- [Semester 2](semester2/): [computer_logic_arithmetic](semester2/computer_logic_arithmetic/), [discrete_math](semester2/discrete_math/), [oop](semester2/oop/), [physics](semester2/physics/).

- [Semester 4](semester4/): [acm](semester4/acm/), [basketball](semester4/basketball/), [ca1](semester4/ca1/), [database_organization](semester4/database_organization/), [digital_circuitry](semester4/digital_circuitry/), [environmental_protection](semester4/environmental_protection/), [probability_theory](semester4/probability_theory/), [software_engineering_coursework](semester4/software_engineering_coursework/).

Personal progress can be tracked separately in `progress.yaml`; see the [progress-tracking template](templates/README.md).

Shared report resources are stored in [`templates/`](templates/), while course-specific title pages are kept in the corresponding course's `work/` directory.

Reproducible build output and caches such as `build/`, `target/`, `out/`, `.gradle/`, `.venv/`, and Quartus `db/` and `incremental_db/` are not stored in Git. Source code, project files, and completed reports remain in the repository; PDF and EXE files are managed through Git LFS.

## Usage

Browse the semester directories and select a course. Start with its `README.md` for an operational overview, then use `materials/`, `work/`, or `project/` as applicable.
