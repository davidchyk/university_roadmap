# Introduction to the Linux Operating System

This course covers GNU/Linux installation and administration, command-line tools, text processing, Bash scripting, packages, processes, permissions, networking, disks, and file systems. The archived syllabus data includes separate variants for Computer Engineering and Software Engineering programs.

## Instructors

- Lecturer: Oleksandr Rokovyi
- Lab instructor: Oleh Alienin

## Workload

- Computer Engineering variant: 150 total hours; 36 lecture hours, 18 lab hours, and 96 self-study hours
- Software Engineering practicum variant: 150 total hours; 36 lecture hours, 36 lab hours, and 78 self-study hours

## Assessment

### Coursework

- Labs: 9 required labs covering installation, text filters, streams and pipelines, file search, processes, users and permissions, packages and libraries, networking, and disk management
- Software Engineering practicum variant only: 1 module test
- Labs may be defended in any order; students must demonstrate their own variant and answer questions. Late defenses carry no penalty.

### Grading System

| Component | Count | Points |
|---|---:|---:|
| Labs — Computer Engineering variant | 9 | 99 (11 each) |
| Labs — Software Engineering practicum variant, before weighting | 9 | 90 (10 each) |
| Module test — Software Engineering practicum variant, before weighting | 1 | 10 |

**Maximum:** 100 points. The source does not explain how formulas that can exceed 100 are normalized.

### Final Assessment

- Type: Pass-fail
- Admission requirements: Defend all 9 labs.
- Automatic grade requirements: Computer Engineering variant — meet the admission requirements and earn at least 60 semester points. No automatic-grade rule is available for the practicum variant.
- Pass-fail interview: 3 theoretical questions worth up to 20 points each. The Computer Engineering formula weights lab points by 0.6 when the interview is taken.
