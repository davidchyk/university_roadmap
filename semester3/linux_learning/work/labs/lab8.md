# ЛР №8 — Налаштування та діагностика мережі (усі варіанти)

# Підготовка (для всіх варіантів)
```bash
ip addr show                     # показати усі мережеві інтерфейси, їхні IP/MAC, стани (аналог ifconfig)
ip route show                    # показати таблицю маршрутизації (шлях за замовчуванням, мережі, через які GW)
ping -c 3 google.com.ua          # 3 ICMP-ехо до домену; перевірка доступності й затримки (ms)
host 8.8.8.8                     # DNS-запит (reverse lookup для IP → ім’я вузла, якщо існує PTR)
ping -c 3 127.0.0.1              # перевірка локального стека TCP/IP (loopback) — має завжди відповідати
traceroute -m 3 google.com       # маршрут до вузла, максимум 3 «стрибки» (hops) для швидкого перегляду
# Примітка: якщо traceroute не встановлений — sudo apt install traceroute
```
# ========================= ВАРІАНТ 1 =========================
```bash

# A1: KPI.UA — доступність і середній час
ping -c 4 kpi.ua                 # 4 ICMP-ехо; в підсумку дивись packet loss і avg rtt у статистиці

```
# ========================= ВАРІАНТ 2 =========================
```bash

# A2: KPI.UA — маршрутизатори на шляху

```
# ========================= ВАРІАНТ 3 =========================
```bash

```
# ========================= ВАРІАНТ 4 =========================
```bash

# A4: COMSYS.KPI.UA — маршрутизатори на шляху

```


```bash
# Альтернатива: ss -tan | wc -l
```

# ========================= ВАРІАНТ 13 =========================
```bash

# A13: Перевірка HTTP server (порти 80/443)
sudo netstat -tlnp | egrep ':80|:443'   # показати, чи є LISTEN на 80/443 і якими процесами
# Альтернатива: sudo ss -tlnp '( sport = :80 or sport = :443 )'

```

# Перелік команд і опцій, що використовуються в ЛР №8 (і що вони роблять)

## Базова діагностика мережі (підготовка)
- `ip addr show` — показує **IP-адреси** та конфігурацію всіх мережевих інтерфейсів.
- `ip route show` — показує **маршрутну таблицю** (шляхи за замовчуванням, шлюзи, метрики).
- `ping -c 3 google.com.ua` — перевірка доступності домену `google.com.ua`; `-c 3` — 3 пакети.
- `host 8.8.8.8` — DNS-запит: знайти **доменне ім’я** для IP (або IP для домену).
- `ping -c 3 127.0.0.1` — перевірка **локального стеку TCP/IP** (loopback).
- `traceroute -m 3 google.com` — показати маршрут до `google.com`, максимум 3 переходи (`-m 3`).
