# Лабораторна робота 3.2 — Java monitors

Варіант 16:

```text
A = p * (sort(d * B + Z * MM) * (MX * MT)) + (B * Z) * Z
```

Компіляція і запуск:

```bash
cd src
javac *.java
java Main
```

Програма вводить `N`, а потім по одному значенню для заповнення кожного
вектора або матриці та значення скалярів. Порядок блоків введення потоків
може змінюватися; орієнтуватися потрібно на запрошення `T1`, `T3`, `T4`.

Для перевірки при `N = 4` і значенні `1` для всіх операндів очікується:

```text
A = [84, 84, 84, 84]
```

Час вимірюється після завершення всього введення і до готовності всіх частин
результату, без урахування друку вектора.
