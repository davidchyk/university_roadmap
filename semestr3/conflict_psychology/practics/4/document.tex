    \section*{Вступ}
    Міжособистісні конфлікти супроводжують людину впродовж усього життя: у родині, навчанні, професійній діяльності, дружньому колі. 
    Вони виникають тоді, коли стикаються відмінні позиції, інтереси, цінності або емоційні стани людей. 
    Розуміння причин міжособистісних конфліктів є необхідною передумовою їх профілактики та конструктивного розв’язання.

    Аналіз причин дає змогу:
    \begin{itemize}
        \item вчасно розпізнавати \textit{передконфліктні ситуації};
        \item зменшувати інтенсивність емоційного напруження;
        \item обирати адекватні стратегії поведінки;
        \item формувати культуру ненасильницької комунікації.
    \end{itemize}

    \section*{Поняття міжособистісного конфлікту}
    \textbf{Міжособистісний конфлікт}~--- це зіткнення протилежно спрямованих цілей, інтересів, позицій або установок двох чи більше осіб, 
    що супроводжується емоційною напругою й переживається як проблемна ситуація взаємодії.

    Ключові характеристики міжособистісного конфлікту:
    \begin{itemize}
        \item наявність \textit{не менше двох суб’єктів} взаємодії;
        \item \textit{усвідомлене} протиріччя (кожна сторона відчуває або усвідомлює несумісність позицій);
        \item \textit{емоційна залученість} (образа, роздратування, гнів, тривога тощо);
        \item \textit{поведінкове вираження} протистояння (словесні суперечки, демонстративна поведінка, уникнення спілкування тощо).
    \end{itemize}

    \section*{Загальна класифікація причин міжособистісних конфліктів}
    Причини міжособистісних конфліктів можна умовно поділити на кілька великих груп.

    \subsection*{Об’єктивні та суб’єктивні причини}
    \textbf{Об’єктивні причини}:
    \begin{itemize}
        \item обмеженість ресурсів (час, гроші, можливості, статус, інформація);
        \item суперечливі вимоги з боку організації, групи або керівництва;
        \item нечіткий розподіл ролей і функцій, дублювання обов’язків;
        \item структурні недоліки організації (ієрархічні бар’єри, перевантаження, нечіткі інструкції).
    \end{itemize}

    \textbf{Суб’єктивні причини}:
    \begin{itemize}
        \item індивідуальні особливості характеру (імпульсивність, тривожність, ригідність);
        \item особистісні цінності й установки, що не збігаються з цінностями інших;
        \item низький рівень емоційної регуляції (невміння стримувати агресію, керувати тривогою);
        \item попередній конфліктний досвід, що впливає на очікування та інтерпретації ситуацій.
    \end{itemize}

    \subsection*{Когнітивні, емоційні та поведінкові чинники}
    \textbf{Когнітивні причини} пов’язані з особливостями сприйняття й мислення:
    \begin{itemize}
        \item стереотипи та упередження щодо інших людей або груп;
        \item \textit{атрибутивні помилки} (схильність приписувати іншим негативні риси замість врахування ситуаційних факторів);
        \item вибіркова увага до негативної інформації;
        \item різна інтерпретація одних і тих самих подій.
    \end{itemize}

    \textbf{Емоційні причини}:
    \begin{itemize}
        \item накопичені образи та невисловлене невдоволення;
        \item ревнощі, заздрість, почуття несправедливості;
        \item емоційне вигорання, втома, хронічний стрес;
        \item низька толерантність до фрустрації.
    \end{itemize}

    \textbf{Поведінкові причини}:
    \begin{itemize}
        \item агресивний або пасивно-агресивний стиль взаємодії;
        \item схильність до домінування та авторитарності;
        \item ухилення від відкритого обговорення проблем;
        \item маніпулятивні стратегії спілкування.
    \end{itemize}

    \section*{Комунікативні причини міжособистісних конфліктів}
    Значна частина міжособистісних конфліктів виникає через \textbf{дефекти комунікації}:
    \begin{itemize}
        \item нечіткість або двозначність висловлювань;
        \item відсутність зворотного зв’язку («неперепитали», «не перевірили, чи правильно зрозуміли»);
        \item використання звинувачувальних формулювань («ти завжди…», «ти ніколи…»);
        \item ігнорування \textit{невербальних сигналів} (тон голосу, міміка, жести);
        \item комунікація в стані сильної емоційної напруги (коли здатність слухати й аналізувати різко знижується).
    \end{itemize}

    Окрему роль відіграє \textbf{цифрове спілкування} (соціальні мережі, месенджери), де:
    \begin{itemize}
        \item відсутні або обмежені невербальні підказки;
        \item легше \textit{неправильно інтерпретувати} повідомлення;
        \item частіше виникає імпульсивна реакція (швидка відповідь без усвідомленого аналізу).
    \end{itemize}

    \section*{Особистісні та соціально-психологічні причини}
    \subsection*{Індивідуально-особистісні чинники}
    До особистісних причин міжособистісних конфліктів належать:
    \begin{itemize}
        \item \textbf{тип темпераменту} (підвищена збудливість, схильність до різких реакцій);
        \item \textbf{рівень самооцінки} (занижена або завищена самооцінка підвищує чутливість до критики);
        \item \textbf{Я-концепція} (уразливість образу «Я», потреба в підтвердженні значущості);
        \item \textbf{рівень емпатії} (здатність розуміти й відчувати іншу людину);
        \item \textbf{конфліктність як риса} (стійка схильність до суперництва, домінування).
    \end{itemize}

    \subsection*{Соціально-психологічні фактори}
    \begin{itemize}
        \item \textbf{Рольові конфлікти}~--- невідповідність очікувань щодо ролей («друг», «керівник», «студент», «батько/мати» тощо).
        \item \textbf{Статусні розбіжності}~--- боротьба за вплив, лідерство, визнання в групі.
        \item \textbf{Групові норми}~--- несумісність індивідуальної поведінки з нормами колективу.
        \item \textbf{Культурні відмінності}~--- різні уявлення про прийнятні форми спілкування, дистанцію, вираження емоцій.
    \end{itemize}

    \section*{Типові сфери виникнення міжособистісних конфліктів}
    \textbf{У сім’ї}:
    \begin{itemize}
        \item різні уявлення про розподіл обов’язків;
        \item розбіжності у вихованні дітей;
        \item фінансові питання;
        \item вплив родичів, поколіннєві відмінності.
    \end{itemize}

    \textbf{В навчальному середовищі}:
    \begin{itemize}
        \item суперництво між студентами;
        \item різні очікування від викладача чи групи;
        \item нерівномірний розподіл спільної роботи в командах;
        \item несправедливість, що так сприймається (оцінювання, ставлення).
    \end{itemize}

    \textbf{На роботі}:
    \begin{itemize}
        \item конфлікт інтересів підрозділів;
        \item неузгодженість завдань і ресурсів;
        \item стиль керівництва (авторитарний, директивний);
        \item конкуренція за посади, премії, визнання.
    \end{itemize}

    \section*{Роль емоцій та сприйняття в розвитку конфлікту}
    Навіть незначне об’єктивне протиріччя може перерости в гострий конфлікт, якщо:
    \begin{itemize}
        \item воно торкається \textit{значущих для особи цінностей} (гідність, повага, автономія);
        \item актуалізує \textit{попередні негативні переживання} (старі образи, незавершені конфлікти);
        \item інтерпретується як \textit{навмисне приниження} чи \textit{загроза}.
    \end{itemize}

    Важливу роль відіграють:
    \begin{itemize}
        \item \textbf{когнітивні схеми} («мене ніхто не поважає», «мені завжди заважають»)~--- вони задають «фільтр» сприйняття;
        \item \textbf{очікування} щодо поведінки інших (якщо очікування не виправдовуються, зростає ймовірність конфлікту);
        \item \textbf{емоційна пам’ять} (схильність повертатися до минулих конфліктних епізодів).
    \end{itemize}

    \section*{Профілактика міжособистісних конфліктів (через роботу з причинами)}
    Знання причин міжособистісних конфліктів дозволяє будувати \textit{профілактичні стратегії}:
    \begin{itemize}
        \item \textbf{Удосконалення комунікації}~--- розвиток навичок активного слухання, уточнення смислів, використання «Я-повідомлень» замість звинувачень.
        \item \textbf{Розвиток емоційного інтелекту}~--- усвідомлення й регуляція власних емоцій, емпатійне ставлення до інших.
        \item \textbf{Робота з установками та стереотипами}~--- критичний аналіз власних упереджень, готовність змінювати погляд на ситуацію.
        \item \textbf{Оптимізація умов взаємодії}~--- чіткий розподіл ролей, прозорі правила й критерії оцінювання, справедливий розподіл ресурсів.
        \item \textbf{Навчання конструктивним стратегіям поведінки в конфлікті}~--- співпраця, пошук взаємовигідних рішень, компроміс.
    \end{itemize}

    \section*{Висновки}
    Причини міжособистісних конфліктів багаторівневі й охоплюють об’єктивні умови взаємодії, індивідуально-психологічні особливості, 
    комунікативні й соціально-психологічні чинники. 
    Один і той самий конфлікт рідко має одну-єдину причину: зазвичай це \textit{комбінація} обставин, установок, емоцій та інтерпретацій.

    Усвідомлення цих причин дає можливість:
    \begin{itemize}
        \item своєчасно виявляти передконфліктні ситуації;
        \item змінювати стиль спілкування й поведінки;
        \item переходити від взаємних звинувачень до спільного пошуку рішень;
        \item перетворювати конфлікт із руйнівної події на ресурс розвитку стосунків і особистісного зростання.
    \end{itemize}
