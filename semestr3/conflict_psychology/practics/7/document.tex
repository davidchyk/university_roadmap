    \section*{Вступ}
    Поведінка людини в конфлікті визначається поєднанням її особистісних рис, попереднього досвіду, 
    цінностей, емоційного стану та ситуаційних факторів. 
    Різні люди по-різному реагують на протиріччя: одні схильні до відкритого протистояння, 
    інші уникають конфлікту будь-якою ціною, ще інші шукають співпрацю й спільні рішення.

    Для опису, аналізу та прогнозування конфліктної поведінки розроблено низку \textbf{моделей поведінки в конфлікті}. 
    Вони дозволяють:
    \begin{itemize}
        \item класифікувати типові стилі реагування;
        \item оцінювати сильні та слабкі сторони кожного стилю;
        \item навчати людей більш гнучкому й усвідомленому вибору стратегії.
    \end{itemize}

    \section*{Поняття моделей поведінки в конфлікті}
    \textbf{Модель поведінки в конфлікті}~--- це теоретична схема, що описує типові способи дій та реакцій людини 
    в умовах протистояння інтересів, цілей чи цінностей.

    Основні завдання таких моделей:
    \begin{itemize}
        \item виявити \textit{ключові параметри}, за якими відрізняються стилі поведінки;
        \item представити конфліктну поведінку в \textit{компактній, візуально зрозумілій формі} (матриці, координатні системи);
        \item надати основу для \textit{діагностики} (опитувальники, тести);
        \item слугувати \textit{орієнтиром у навчанні} ефективній поведінці в конфлікті.
    \end{itemize}

    \section*{Модель К. Томаса~--- Р. Кілмана (п’ять стилів поведінки)}
    Однією з найпоширеніших є модель К.~Томаса та Р.~Кілмана, яка описує п’ять базових стилів поведінки в конфлікті. 
    Вона ґрунтується на двох вимірах:
    \begin{itemize}
        \item \textbf{орієнтація на власні інтереси} (асертивність);
        \item \textbf{орієнтація на інтереси іншого} (кооперація).
    \end{itemize}

    Комбінація цих вимірів утворює п’ять стилів:

    \subsection*{1. Суперництво (змагальність, конкуренція)}
    \begin{itemize}
        \item Висока орієнтація на власні інтереси, низька~--- на інтереси іншого.
        \item Людина прагне \textit{виграти конфлікт}, відстояти свою позицію, навіть ціною погіршення стосунків.
        \item Ефективний у ситуаціях, коли:
        \begin{itemize}
            \item рішення потрібно ухвалити швидко;
            \item йдеться про принципові питання без варіантів компромісу;
            \item необхідно захистити важливі цінності чи права.
        \end{itemize}
        \item Ризики: ескалація конфлікту, формування ворожнечі, зниження довіри.
    \end{itemize}

    \subsection*{2. Пристосування}
    \begin{itemize}
        \item Низька орієнтація на власні інтереси, висока~--- на інтереси іншого.
        \item Людина \textit{жертвує своїми потребами} заради збереження стосунків чи уникнення напруги.
        \item Доцільний, коли:
        \begin{itemize}
            \item питання для людини не є принциповим, а для іншої сторони~--- важливе;
            \item потрібно зберегти мир у короткостроковій перспективі;
            \item це свідомий жест доброї волі.
        \end{itemize}
        \item Ризики: накопичення внутрішніх образ, відчуття несправедливості, зниження самоповаги.
    \end{itemize}

    \subsection*{3. Ухилення}
    \begin{itemize}
        \item Низька орієнтація як на власні, так і на чужі інтереси.
        \item Людина \textit{уникає прямого зіткнення}: відкладає обговорення, змінює тему, виходить із контакту.
        \item Може бути доречним, коли:
        \begin{itemize}
            \item емоційна напруга занадто висока, і потрібен час на «охолодження»;
            \item проблема не є суттєвою або вирішиться без втручання;
            \item конфлікт \textit{не в її зоні відповідальності}.
        \end{itemize}
        \item Ризики: накопичення невирішених проблем, перетворення латентних конфліктів на хронічні.
    \end{itemize}

    \subsection*{4. Компроміс}
    \begin{itemize}
        \item Середній рівень орієнтації на власні та чужі інтереси.
        \item Кожна сторона робить \textit{взаємні поступки}, отримуючи частину бажаного.
        \item Ефективний, коли:
        \begin{itemize}
            \item обмежені ресурси або час;
            \item сторони мають \textit{порівняну силу} і готовність домовлятися;
            \item «ідеального» рішення досягти важко.
        \end{itemize}
        \item Ризики: відсутність глибинного вирішення проблеми, «напіврішення», яке не задовольняє повністю нікого.
    \end{itemize}

    \subsection*{5. Співпраця}
    \begin{itemize}
        \item Висока орієнтація і на власні, і на чужі інтереси.
        \item Сторони \textit{спільно шукають рішення}, що максимально враховує потреби всіх.
        \item Передбачає:
        \begin{itemize}
            \item відкритий обмін інформацією;
            \item готовність до глибокого аналізу причин;
            \item креативний пошук нових варіантів.
        \end{itemize}
        \item Оптимальний для \textit{довгострокових стосунків} і складних проблем, але потребує часу, довіри та розвинених навичок комунікації.
    \end{itemize}

    \section*{Модель «подвійної турботи» (dual concern model)}
    Близькою до моделі Томаса~--- Кілмана є загальніша \textbf{модель подвійної турботи}, 
    яка також оперує двома осями:
    \begin{itemize}
        \item турбота про власні інтереси;
        \item турбота про інтереси іншого.
    \end{itemize}

    Залежно від поєднання цих параметрів:
    \begin{itemize}
        \item низька/низька турбота~--- \textit{ухилення};
        \item висока/низька~--- \textit{суперництво};
        \item низька/висока~--- \textit{пристосування};
        \item середня/середня~--- \textit{компроміс};
        \item висока/висока~--- \textit{співпраця}.
    \end{itemize}

    Перевага цієї моделі в тому, що вона:
    \begin{itemize}
        \item наочно показує \textit{баланс між собою й іншим};
        \item дозволяє пояснювати перехід від одного стилю до іншого як зміну рівня турботи;
        \item слугує основою для багатьох опитувальників і тренінгових програм.
    \end{itemize}

    \section*{Інші підходи до класифікації поведінки в конфлікті}
    Окрім моделей, заснованих на асертивності та кооперації, існують й інші підходи.

    \subsection*{Его-захисні стилі поведінки}
    Частина поведінкових стратегій зумовлена \textbf{механізмами психологічного захисту}:
    \begin{itemize}
        \item \textit{раціоналізація} (пошук логічних пояснень своїм агресивним або пасивним діям);
        \item \textit{проекція} (приписування власних негативних почуттів іншому);
        \item \textit{витіснення} (несвідоме «забування» конфліктної ситуації);
        \item \textit{компенсація} (перенесення енергії з конфлікту в іншу сферу).
    \end{itemize}
    У цих випадках поведінка часто має непрямий, неусвідомлений характер.

    \subsection*{Асертивна, агресивна й пасивна поведінка}
    Інший поділ ґрунтується на \textbf{способі відстоювання власних прав}:
    \begin{itemize}
        \item \textbf{пасивна поведінка}~--- уникнення прямого вираження потреб, страх перед відмовою чи конфронтацією;
        \item \textbf{агресивна поведінка}~--- відстоювання своїх прав шляхом тиску, приниження, ігнорування кордонів іншого;
        \item \textbf{асертивна поведінка}~--- відкритий, чесний і поважний спосіб висловлення своїх потреб без порушення прав іншого.
    \end{itemize}

    Асертивність розглядається як \textit{оптимальна модель поведінки} у більшості міжособистісних конфліктів.

    \section*{Фактори, що впливають на вибір моделі поведінки}
    Вибір людиною того чи іншого стилю поведінки визначається поєднанням:

    \subsection*{Особистісних факторів}
    \begin{itemize}
        \item тип темпераменту та рівень емоційної збудливості;
        \item самооцінка та Я-концепція;
        \item попередній досвід успішних/неуспішних конфліктних взаємодій;
        \item рівень емпатії та емоційного інтелекту;
        \item толерантність до невизначеності й фрустрації.
    \end{itemize}

    \subsection*{Ситуаційних факторів}
    \begin{itemize}
        \item значущість предмета конфлікту для сторін;
        \item часові обмеження;
        \item наявність/відсутність зовнішнього контролю (керівництво, правила, норми);
        \item баланс сил між учасниками (формальна й неформальна влада);
        \item контекст (сім’я, навчання, робота, публічний простір).
    \end{itemize}

    \section*{Адаптивність і гнучкість поведінки в конфлікті}
    Сучасна конфліктологія підкреслює, що \textbf{немає «ідеального» універсального стилю} для всіх ситуацій. 
    Ключовою характеристикою зрілої конфліктної поведінки є \textit{гнучкість}:
    \begin{itemize}
        \item здатність \textit{усвідомлювати свій домінуючий стиль};
        \item вміння \textit{адаптувати поведінку} до вимог конкретної ситуації;
        \item перехід від автоматичних реакцій до \textit{свідомого вибору стратегії}.
    \end{itemize}

    Навчання моделям поведінки в конфлікті дає змогу:
    \begin{itemize}
        \item розширити \textit{поведінковий репертуар};
        \item зменшити імовірність деструктивних реакцій у стресових умовах;
        \item підвищити ефективність міжособистісної та професійної взаємодії.
    \end{itemize}

    \section*{Розвиток ефективних моделей поведінки}
    Формування більш конструктивних моделей поведінки здійснюється через:
    \begin{itemize}
        \item \textbf{психопросвіту} (знайомство з теоріями та моделями конфліктної поведінки);
        \item \textbf{тренінги} (рольові ігри, моделювання конфліктних ситуацій, зворотний зв’язок);
        \item \textbf{коучинг і психотерапію} (опрацювання особистісних бар’єрів та автоматичних патернів);
        \item \textbf{саморефлексію} (аналіз власних конфліктних епізодів, ведення щоденника, усвідомлення тригерів).
    \end{itemize}

    Особливу роль відіграє розвиток:
    \begin{itemize}
        \item \textbf{асертивності} як базової навички;
        \item \textbf{емпатії} та здатності бачити ситуацію з різних перспектив;
        \item \textbf{навыків співпраці} й спільного вирішення проблем.
    \end{itemize}

    \section*{Висновки}
    Моделі поведінки людини в конфлікті дають системне уявлення про типові стилі реагування та їхні наслідки. 
    Вони слугують інструментом діагностики, навчання й саморозвитку.

    Основні висновки:
    \begin{itemize}
        \item Поведінка в конфлікті може бути описана через \textit{баланс інтересів}~--- власних і чужих.
        \item Моделі К.~Томаса~--- Р.~Кілмана та «подвійної турботи» виділяють п’ять базових стилів: суперництво, пристосування, ухилення, компроміс, співпраця.
        \item Жоден стиль не є однозначно «поганим» або «хорошим»~--- їхня ефективність залежить від контексту.
        \item Ключем до конструктивної поведінки в конфлікті є \textit{гнучкість, усвідомленість і розвиток особистісних ресурсів}.
    \end{itemize}
