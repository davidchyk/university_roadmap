# ЛР №5 — Управління процесами (усі варіанти)
# Підготовка (виконати один раз перед варіантами)
- запустити довгий процес і запам’ятати PID:
```bash
sleep 1000 &        # запустити довгий процес у фоні
echo $!             # показати PID щойно запущеного фонового процесу

# якщо стартували у форграунді:
#   Ctrl+Z  → призупинити (T)
#   bg      → продовжити у фоні

ps -o ppid= -p <PID>     # показати PPID (батьківський PID) для вказаного процесу
pstree -ap | grep <PID>  # дерево процесів із PID і аргументами; фільтруємо за PID
top                      # інтерактивний монітор процесів; натисни 'L' → введи PID → 'q' вийти
kill <PID>               # ввічливе завершення (SIGTERM)
kill -9 <PID>            # примусове завершення (SIGKILL), якщо процес «не слухається»
```

``` bash
# TOP — налаштувати колонки у порядку:
#   USER | PID | %CPU | %MEM | COMMAND
# Інтерактивно в top:
#   1) Запустити: top
#   2) 'f' (Fields Management) → пробілом лишити USER, PID, %CPU, %MEM, COMMAND

#
# Перевірочний аналог через ps:
ps -eo user,pid,pcpu,pmem,cmd --sort=-pcpu
---
# top → 'f' → лишити USER, PID, %CPU, %MEM, COMMAND; '<' '>' — порядок; 'W' — зберегти, 'q' — вийти
ps -eo user,pid,pcpu,pmem,cmd --sort=-pcpu
# приблизний «знімок» як у top, відсортований за %CPU
```

# Перелік команд і опцій, що використовуються в ЛР №5 (і що вони роблять)

## Запуск, фон, ідентифікатори
- `sleep 1000 &` — запускає процес у **фоні**; оболонка одразу повертає контроль.
- `echo $!` — виводить **PID** останнього фонового процесу.
- `Ctrl+Z` — призупиняє поточний форграунд-процес (SIGTSTP), переводить у стан **stopped**.
- `bg` / `fg` — продовжити призупинений процес у фоні / повернути у форграунд.
- `jobs` — список задач (фон/призупинені) поточної оболонки.

## Ієрархія процесів і батьківські PID
- `ps -o ppid= -p <PID>` — вивести **PPID** (parent PID) для заданого процесу.
- `pstree -ap` — дерево процесів:
  - `-a` — показує **аргументи** команд,
  - `-p` — показує **PID**.
- `top` — інтерактивний монітор процесів:
  - `L` — пошук за PID,
  - `f` — керування полями/колонками,
  - `>`/`<` — порядок колонок,
  - `W` — зберегти конфігурацію,
  - `q` — вийти.

## Завершення процесів
- `kill <PID>` — надіслати сигнал (за замовчуванням **SIGTERM** = 15) для коректного завершення.
- `kill -9 <PID>` — **SIGKILL** (9), примусове негайне завершення (необроблюваний).
- `pkill -u <USER>` — закінчити **усі** процеси певного користувача (спершу SIGTERM).
- `pkill -KILL -u <USER>` — примусово завершити, якщо щось лишилося.
- `pkill -t pts/4` — завершити всі процеси, приписані до TTY `pts/4`.
- `pgrep -u <USER> -l` — перелік процесів користувача (`-l` додає імена команд).

## Перегляд процесів (`ps`) і важливі стовпці
Загальна форма: `ps [відбір] -o поля --sort=ключ`

- Відбір:
  - `-e` — усі процеси,
  - `-u "$USER"` — лише процеси конкретного користувача,
  - `-t <TTY>` — процеси, прив’язані до терміналу (наприклад, `ps -t pts/3`).
- Поля (приклади з ЛР):
  - `pid` — ідентифікатор процесу,
  - `ppid` — батьківський PID,
  - `user` — власник процесу,
  - `cmd` — команда (повна),
  - `stat` — **стан процесу** (див. нижче),
  - `pcpu` — % використання CPU (моментний зріз),
  - `pmem` — % використання пам’яті,
  - `vsz`/`vsize` — віртуальний розмір адресного простору (KB),
  - `pri` — пріоритет планувальника,
  - `time` — сумарний **CPU time** (HH:MM:SS),
  - `lstart` — дата+час старту процесу,
  - `etime` — час, що минув від старту (формат дні-год:хв:сек).
- Сортування:
  - `--sort=-vsz` — за спаданням VSZ,
  - `--sort=-pcpu` — за спаданням %CPU,
  - `--sort=pri` — за пріоритетом (зростання).
