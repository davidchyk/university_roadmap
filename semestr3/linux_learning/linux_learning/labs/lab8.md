# Перелік команд і опцій, що використовуються в ЛР №8 (і що вони роблять)

## Базова діагностика мережі (підготовка)
- `ip addr show` — показує **IP-адреси** та конфігурацію всіх мережевих інтерфейсів.
- `ip route show` — показує **маршрутну таблицю** (шляхи за замовчуванням, шлюзи, метрики).
- `ping -c 3 google.com.ua` — перевірка доступності домену `google.com.ua`; `-c 3` — 3 пакети.
- `host 8.8.8.8` — DNS-запит: знайти **доменне ім’я** для IP (або IP для домену).
- `ping -c 3 127.0.0.1` — перевірка **локального стеку TCP/IP** (loopback).
- `traceroute -m 3 google.com` — показати маршрут до `google.com`, максимум 3 переходи (`-m 3`).
