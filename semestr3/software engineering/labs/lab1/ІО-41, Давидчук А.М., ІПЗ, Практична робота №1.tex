    \textbf{\underline{Тема:}} «Підготовка програмного проекту. Збірка проекту за допомогою Ant, Maven та Gradle».
    
    \vspace{1em}

    \textbf{\underline{Мета:}} Отримання базових навичок з використання мови XML.
    Вивчення структури типового програмного проекту, форматів стандартних файлів опису проекту.
    Вивчення формату JAR. Здобуття навичок з використання засобів автоматизації процесу збірки програмних проектів на мові Java - Apache ANT (Another Neat Tool),
    Maven, Gradle.

    \begin{center} \textbf{\Large Практична частина} \end{center}

    \setlength{\parindent}{1.5em}

    Мій номер залікової книги: 4106. Звідси мій варіант до 1 завдання: $4106\text{ mod }9 = 2$, звідси я маю
    створити в каталозі out jar-архів з усіх файлів проекту з розширеннями java, js, html, htm. Скопіювати архів в корінь проекту.

    \textbf{\underline{Програмний код для завдання №1 (\texttt{project1$\backslash$build.xml}):}}

    \begin{minted}{xml}
<?xml version="1.0" encoding="UTF-8"?>
<project name="lab1-artem" default="variant2" basedir=".">
    <!-- Author: Artem Davydchyk, Group: IO-41 -->
    <property name="out.dir" value="${basedir}/out"/>
    <property name="archive.name" value="sources_web.jar"/>
    <target name="init">
        <mkdir dir="${out.dir}"/>
    </target>
    <target name="jar.sources.web" depends="init">
        <jar destfile="${out.dir}/${archive.name}">
            <fileset dir="${basedir}">
                <include name="**/*.java"/>
                <include name="**/*.js"/>
                <include name="**/*.html"/>
                <include name="**/*.htm"/>
                <exclude name="out/**"/>
                <exclude name=".idea/**"/>
                <exclude name="**/*.class"/>
            </fileset>
        </jar>
    </target>
    <target name="variant2" depends="jar.sources.web">
        <copy file="${out.dir}/${archive.name}" todir="${basedir}"/>
    </target>
    <target name="clean">
        <delete dir="${out.dir}"/>
        <delete file="${basedir}/${archive.name}"/>
    </target>
</project>
    \end{minted}

    \textbf{\underline{Додатково Gradle \texttt{project2$\backslash$build.gradle}}}:

    \begin{minted}{text}
plugins {
    id 'java'
    id 'application'
}

group = 'ua.artem'

java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }

repositories { mavenCentral() }

dependencies {
    implementation 'com.google.code.gson:gson:2.11.0'
}

application {
    mainClass = 'ua.artem.Main'
}

tasks.jar {
    archiveBaseName = 'project2'
    duplicatesStrategy = DuplicatesStrategy.EXCLUDE
    manifest { attributes 'Main-Class': application.mainClass }
    from {
        configurations.runtimeClasspath.collect { it.isDirectory() ? it : zipTree(it) }
    }
}

    \end{minted}

    \textbf{\underline{Висновок:}} У ході виконання практичної роботи я ознайомився з процесом підготовки та
збірки програмних проєктів мовою Java за допомогою систем автоматизації
Apache Ant, Maven та Gradle. Для Ant було розроблено власний сценарій
збірки (build.xml), який автоматизує створення архівів JAR та копіювання їх у
потрібні каталоги. Для Maven і Gradle було створено окремі конфігураційні
файли (pom.xml та build.gradle), у які додано сторонню бібліотеку Gson із
репозиторію Maven Central. Було налаштовано формування виконуваного
FatJar-файлу, що містить усі залежності, та реалізовано клас з головним
методом, який виводить у консоль JSON-об’єкт з моїми даними. Робота дозволила закріпити навички роботи з XML-форматом, зрозуміти
структуру типових проєктів на Java та засвоїти принципи використання
інструментів автоматизації збірки.
