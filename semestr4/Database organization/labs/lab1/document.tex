    \noindent
    \textbf{\underline{Тема:}} «Збір вимог та розробка схем ER».

    \vspace{1em}

    \noindent
    \textbf{\underline{Мета:}} Навчитися збирати та документувати вимоги до інформаційної системи, виділяти з них ключові сутності, їх атрибути та зв’язки, а також побудувати концептуальну ER-діаграму (Entity–Relationship Diagram), що відображає модель даних і слугує основою для подальшого проєктування та реалізації бази даних у СУБД.

    \begin{center} \textbf{\large Хід роботи} \end{center}

    \noindent
    Змоделюємо систему чата клієнта із певною моделлю ШІ -- система повинна:

    \begin{enumerate}
        \item зберігати історію чатів і повідомлень;
        \item дозволяти прикріплювати файли до повідомлень;
        \item фіксувати, якою моделлю і з якими параметрами була згенерована відповідь;
    \end{enumerate}

    \noindent
    Звідси зацікавлені сторони:

    \begin{enumerate}
        \item Користувач (User): створює чати, обирає модель ШІ, надсилає повідомлення, прикріплює файли;
        \item Система/AI: генерує відповіді, зберігає метадані.
    \end{enumerate}

    \noindent
    Визначимо також основні сценарії, які можуть відбуватись у нашій системі:

    \begin{enumerate}
        \item Користувач створює новий чат;
        \item Користувач надсилає повідомлення в чат;
        \item Користувач прикріплює файл до повідомлення (картинка/пдф/код тощо).
        \item Система генерує відповідь AI і зберігає її.
    \end{enumerate}

    \noindent
    Тепер визначимо основних сутностей, які є частиною цієї системи:

    \vspace{1em}

    \noindent
    User:

    \begin{enumerate}
        \item user\_id (унікальний код користувача);
        \item username (не унікальний нік користувача);
        \item age (вік користувача);
        \item email (унікальна пошта користувача);
        \item country (країна користувача);
        \item created\_at (дата створення акаунту користувача).
    \end{enumerate}

    \vspace{1em}

    \noindent
    Chat:

    \begin{enumerate}
        \item chat\_id (унікальний код розмови (чату));
        \item owner (власник чату);
        \item title (назва чату);
        \item email (унікальна пошта користувача);
        \item created\_at (дата створення чату).
    \end{enumerate}

    \vspace{1em}

    \noindent
    Message:

    \begin{enumerate}
        \item message\_id (унікальний код текстового повідомлення);
        \item owner (власник текстового повідомлення);
        \item text (текст повідомлення);
        \item to\_model (обрана модель генерації відповіді на дане текстове повідомлення);
        \item created\_at (дата створення текстового повідомлення).
    \end{enumerate}
